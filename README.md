# Aplicativo de Relatórios de Campo (Mobile-First)

Sistema offline estruturado para engenharia de campo, permitindo captura de relatórios, dados georreferenciados, exportação automática em PDF limpo (4 fotos por página), planilhas Excel integradas e geração de waypoints KML restritos.

## Estrutura do Projeto
- `index.html`: Interface visual otimizada para dispositivos móveis com suporte a Safe Areas e Dark Mode.
- `engine.js`: Motores independentes para processamento local de arquivos (PDF, Excel e KML).
- `app.js`: Gerenciamento de estados da aplicação e controladores de eventos.
